Render Markdown
with React Components

A powerful React component library that wraps marked.js, allowing you to render custom React components for markdown tokens instead of plain HTML strings.

Get Started View on GitHub

Custom Components

Replace any markdown token with your own React components. Full control over rendering.

Built on marked.js

Leverages the power and flexibility of marked.js under the hood with a React-friendly API.

TypeScript Ready

Fully typed with TypeScript for the best developer experience and type safety.

Get Started

Installation

# npm
npm install react-marked-renderer
# yarn
yarn add react-marked-renderer
# pnpm
pnpm add react-marked-renderer

Quick Example

Code
import { Markdown } from 'react-marked-renderer';

const markdown = `
# Hello World

This is **bold** text.

- Item 1
- Item 2
- Item 3
`;

function App() {
  return <Markdown content={markdown} />;
}

Custom Renderers

import { Markdown } from 'react-marked-renderer';

const customRenderers = {
  heading: ({ level, children }) => (
    <h{level} className="custom-heading">
      {children}
    </h{level}>
  ),
  code: ({ lang, text }) => (
    <SyntaxHighlighter language={lang}>
      {text}
    </SyntaxHighlighter>
  ),
};

<Markdown content={markdown} renderers={customRenderers} />
